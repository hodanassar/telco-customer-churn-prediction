# Notebooks

This folder contains the Jupyter notebook for the IBM Telco Customer Churn Prediction project.

## File

- `IBM_Telco_Churn_Capstone.ipynb` — main notebook for data preprocessing, exploratory data analysis, model development, model evaluation, feature importance, SHAP interpretation, and churn risk segmentation.

## Notebook Overview

The notebook includes:

- Loading and exploring the IBM Telco Customer Churn dataset
- Cleaning and preparing the data
- Encoding categorical variables
- Scaling numerical variables where needed
- Splitting the data into training and testing sets
- Training and comparing machine learning models
- Evaluating model performance using ROC-AUC, accuracy, precision, recall, and F1-score
- Identifying key churn drivers
- Creating customer churn risk segments: low, medium, and high risk

The final model outputs were used to support the Tableau dashboard and business recommendations.
