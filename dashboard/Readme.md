# Tableau Dashboard

This folder contains screenshots and supporting files for the Tableau dashboard created for the IBM Telco Customer Churn Prediction project.

The dashboard was designed to present model outputs and business insights in an executive-style format. It highlights customer churn risk segments, key churn drivers, and patterns related to contract type, tenure, internet service, and monthly charges.

## Dashboard Purpose

The purpose of the dashboard is to help business users:

- Identify high-risk customers for retention outreach
- Understand the main drivers of churn
- Compare churn risk across customer segments
- Translate machine learning predictions into actionable business decisions

## Dashboard Highlights

- Total scored customers
- Low, medium, and high churn-risk segments
- Top churn drivers
- Churn probability by customer characteristics
- Business recommendations for targeted retention actions
