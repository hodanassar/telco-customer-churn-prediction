# Presentation

This folder contains the presentation materials for the IBM Telco Customer Churn Prediction capstone project.

The presentation summarizes the project background, business problem, methodology, model comparison, churn risk segmentation, Tableau dashboard, and final business recommendations.

## Files

- `Nassar_Hoda_Capstone_Presentation.pptx` — capstone presentation slides
- `Nassar_Hoda_Capstone_CoverPage_Abstract.pdf` — project cover page and abstract

## Presentation Overview

The presentation covers:

- Why customer churn prediction matters in telecom
- Overview of the IBM Telco Customer Churn dataset
- Exploratory data analysis findings
- Data preprocessing and model development
- Comparison of Logistic Regression, Random Forest, and XGBoost
- Key churn drivers using feature importance and SHAP
- Customer risk segmentation into low, medium, and high risk groups
- Tableau dashboard walkthrough
- Business recommendations for customer retention
